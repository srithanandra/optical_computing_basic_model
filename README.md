# Optical computing basic model

Minimal PyTorch MNIST training script.

## Setup

```bash
python -m venv .venv
```

Activate the venv:

- Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Run

```bash
python -m src.main
```

The MNIST dataset will be downloaded to `data/` on first run.
